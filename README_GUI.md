1. **双击 `启动.bat` 文件**
   - 会自动安装依赖
   - 自动启动程序
   - 最简单的方式

### 方法2：手动运行

1. **打开命令行**（Win + R → cmd）

2. **进入项目文件夹**
   ```bash
   cd Desktop\watermark-batch-tool-main
   ```

3. **安装依赖**（首次运行）
   ```bash
   pip install -r requirements.txt
   ```

4. **运行程序**
   ```bash
   python watermark_gui.py
   ```

## 🖥️ 使用界面说明

### 左侧配置面板

#### 📁 源文件夹
- 点击 "🔍 浏览" 按钮选择包含图片的文件夹
- 支持两种模式：
  - **单个文件夹模式**：文件夹内直接放图片
  - **多文件夹模式**：文件夹内有多个子文件夹，每个子文件夹包含图片

#### 📤 输出文件夹
- 点击 "🔍 浏览" 按钮选择输出位置
- 处理完成的 ZIP 文件会保存在这里

#### 📝 水印文字
- 输入要添加的水印文字
- 默认为：© 2024
- 支持中文和英文

#### 🎨 水印样式
- **紧迫感**：红色，右下角，醒目
- **优雅感**：灰色，中心，斜角
- **警告感**：黄色，左上角，鲜明
- **品牌感**：深灰色，底部中心，专业

#### 📏 水印大小
- 小：30px
- 中：50px（推荐）
- 大：80px

#### 💧 透明度
- 低：50%（50% = 128）
- 中：70%（70% = 179，推荐）
- 高：90%（90% = 230）
- 范围：0-255（0=完全透明，255=完全不透明）

#### 🖼️ 输出格式
- **PNG**：无损格式，文件较大，适合高质量
- **JPG**：有损格式，文件较小，适合日常
- **原格式**：保持原格式不变（推荐）

#### ⏭️ 跳过第一张
- 勾选时：每个文件夹的第一张图片不添加水印
- 不勾选时：所有图片都添加水印
- 建议保持勾选（保留原始封面）

### 右侧日志面板

显示处理的实时日志，包括：
- ✅ 成功处理的文件
- ❌ 处理失败的文件
- ℹ️ 处理信息
- ⏭️ 跳过的文件

### 底部按钮

- **🚀 开始处理**：开始处理选定的文件夹
- **🗑️ 清空日志**：清空日志面板
- **❌ 退出**：关闭程序

## 📖 使用示例

### 示例1：处理单个文件夹

**文件夹结构**
```
 my_photos/
 ├── photo1.jpg
 ├── photo2.jpg
 ├── photo3.jpg
 └── photo4.jpg
```

**操作步骤**
1. 点击 "📁 源文件夹" 的 "🔍 浏览" 选择 `my_photos` 文件夹
2. 点击 "📤 输出文件夹" 的 "🔍 浏览" 选择输出位置
3. 输入水印文字：`© 2024 My Studio`
4. 选择水印样式：`紧迫感`
5. 其他配置保持默认
6. 点击 "🚀 开始处理"

**结果**
```
输出文件夹/
└── my_photos_watermarked.zip
    ├── photo1.jpg        (原始，无水印)
    ├── photo2.jpg        (已添加水印)
    ├── photo3.jpg        (已添加水印)
    └── photo4.jpg        (已添加水印)
```

### 示例2：批量处理多个文件夹

**文件夹结构**
```
 source_folder/
 ├── Project_A/
 │   ├── image1.jpg
 │   ├── image2.jpg
 │   └── image3.jpg
 ├── Project_B/
 │   ├── photo1.jpg
 │   ├── photo2.jpg
 │   └── photo3.jpg
 └── Project_C/
     ├── pic1.jpg
     ├── pic2.jpg
     └── pic3.jpg
```

**操作步骤**
1. 点击 "📁 源文件夹" 的 "🔍 浏览" 选择 `source_folder` 文件夹
2. 点击 "📤 输出文件夹" 的 "🔍 浏览" 选择输出位置
3. 配置水印设置
4. 点击 "🚀 开始处理"

程序会自动处理所有子文件夹！

**结果**
```
输出文件夹/
├── Project_A_watermarked.zip
├── Project_B_watermarked.zip
└── Project_C_watermarked.zip
```

## ⚙️ 常见问题

### Q: 为什么要跳过第一张图片？
**A:** 保留原始封面/首图，不影响美观。如果不需要，可以取消勾选。

### Q: 可以处理多少张图片？
**A:** 没有限制。取决于电脑性能和内存。通常 1000 张图片需要 5-10 分钟。

### Q: 原始图片会被修改吗？
**A:** 不会。原始图片保持不变，所有处理在临时文件夹进行，最后打包成 ZIP。

### Q: 支持哪些图片格式？
**A:** 支持 PNG、JPG、JPEG、BMP、GIF、WebP。

### Q: 可以中途停止处理吗？
**A:** 可以关闭程序。已完成的 ZIP 文件会保存。

### Q: 处理失败怎么办？
**A:** 查看日志面板的错误信息。常见原因：
- 图片文件损坏
- 文件权限问题
- 磁盘空间不足

## 🛠️ 故障排除

### 问题：点击按钮没反应
**解决**：
1. 确保选择了源文件夹和输出文件夹
2. 确保选择的文件夹确实存在
3. 尝试重启程序

### 问题：找不到图片
**解决**：
1. 确认文件夹里确实有图片
2. 检查文件扩展名（.jpg、.png 等）
3. 确保文件不是快捷方式

### 问题：处理速度慢
**解决**：
1. 检查图片文件大小
2. 关闭其他占用内存的程序
3. 尝试分批处理

### 问题：水印显示乱码
**解决**：
1. 这通常是字体问题，不影响实际处理
2. 生成的图片应该是正常的
3. 可以尝试修改源代码的字体设置
